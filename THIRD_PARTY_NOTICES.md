# Third-party notices

Перечень сторонних компонентов, моделей, датасетов, сервисов и смоделированных
интеграций, которые использует решение (требование формата сдачи, ТЗ стр. 8).

Лицензии Go-модулей определены по файлам LICENSE в кэше модулей для версий
из `go.mod`. Полный список транзитивных Go-зависимостей с хэшами — `go.sum`.

## Языковые модели

Используются **только модели из утверждённого списка кейса** (Приложение 3 ТЗ)
по общему ключу организаторов. Вызов любой другой модели gateway отбивает
(`MODEL_NOT_ALLOWED`), список — [configs/llm.yaml](configs/llm.yaml).

| Модель | Для чего у нас |
|---|---|
| Gemma 4 26B A4B | классификация, извлечение, простые преобразования |
| Qwen3.6 35B A3B | общий анализ и генерация текста |
| GLM-5.3-Flash | шаги глубокого рассуждения и критик |
| Kimi-K2.6 | альтернатива на рассуждение и критика |
| DeepSeek-V4.1-Flash | поиск взаимосвязей между событиями |
| Qwen3-VL-30B-A3B-Instruct | резерв: графики и таблицы из PDF аналитики |

Условия использования моделей — по правилам хакатона и провайдера организаторов.
Внешние AI-сервисы, сторонние API эмбеддингов, готовые агентные и мультиагентные
фреймворки не используются (Приложение 3 ТЗ).

Список и включённость лент — [миграция 00002](internal/infra/db/postgres/migrations/00002_seed_sources.up.sql).
