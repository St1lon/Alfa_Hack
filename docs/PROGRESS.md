## Как читать и обновлять

**Статусы:**

| Значок | Что значит |
|---|---|
| ✅ | Готово: написано, запускается, проверено вживую |
| 🔧 | В работе прямо сейчас |
| ⏳ | Не начато, но срок ещё не горит |
| 🚨 | Под угрозой: сроки или блокер, нужна помощь команды |
| ⛔ | Заблокировано: ждём чужую задачу или ответ организаторов |
| 🗑 | Решили не делать (с причиной) |

**Правила:**

1. У каждой задачи есть **ID** (`G1-03`, `J-05`...). В коммитах и PR ссылайтесь на ID:
   `G1-03: оркестратор, ретраи с бэкоффом`. Так по истории видно, кто что закрыл.
2. Приоритеты из плана: **P0** — без этого решения нет, **P1** — заметно добавляет
   баллов, **P2** — если останется время. P0 чужого участника важнее своего P1.
3. Меняете статус на 🚨 или ⛔ — сразу пишете строку в разделе «Блокеры».
4. Что-то решили не делать — ставите 🗑 и пишете причину, не удаляете строку.
   Через три дня никто не помнит, почему этого нет.
5. Поменяли общий контракт (БД, API, формат инсайта) — пишете в «Решения» и
   предупреждаете остальных: контракты заморожены, молча их менять нельзя.

## Решения, которые уже приняты

1. **Монорепозиторий, один Go-модуль, три бинаря** (`go-ingest`, `llm-gateway`, `go-api`):
   общие domain, миграции и инфраструктура БД, никакого дублирования схемы.
2. **LLM-Gateway — отдельный сервис, а не библиотека.** Ключ есть только у него,
   поэтому Java и Python физически не могут обойти бюджет и аудит.
3. **Кодогенерацию из OpenAPI не используем** (четыре стека, восемь дней):
   спека пишется руками и держится в синхроне с хендлерами. Расхождение — баг.
4. **Деньги считаем в копейках (`int64`)**, включая стоимость вызовов моделей.
5. **Размерность эмбеддинга — 768.** Меняется только миграцией и только по согласию.
6. **Справочники нормализованы таблицами** (`pipeline_statuses`, `attribution_types`),
   а не `CHECK`/`ENUM`: бизнес-правила живут в коде, БД держит целостность.
7. **Идемпотентность пайплайна** — уникальным индексом `(story_id, company_id, model_version)`
   на `insights`, а не проверками в коде.
8. **Источники не удаляем, а выключаем** флагом `enabled`: история парсинга
   остаётся воспроизводимой.
