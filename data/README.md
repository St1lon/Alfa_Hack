# Данные кейса

Файлы датасета и аналитики ЦМИ **не коммитятся** (см. `.gitignore`): они большие
и выданы организаторами. Положите их здесь локально и на внешнем сервере.

```
data/
  df_Uid_data_hack.csv   — юрлица: ОКВЭД, регион, выручка, продуктовые метки, ФТС
  persons.csv            — связи ФЛ и ЮЛ (SYNTHETIC_F), город и регион проживания
  payments.csv           — граф платежей: PAYER, BENEFICIARY, PAY_AMT, PAY_CNT
  research/              — 9 аналитических материалов ЦМИ Альфа-Банка (PDF)
```

Кто этим пользуется:

- `data/*.csv` → загрузчик Go #2 (задача G2-01) кладёт их в `companies`,
  `company_persons`, `counterparty_edges`;
- `data/research/*.pdf` → загрузчик Go #1 (задача G1-13) режет на чанки
  300–600 токенов с обязательными полями «документ» и «страница» —
  на них держится провенанс и позиция банка у Java.
