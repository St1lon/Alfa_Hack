## Что важно знать про CSV (Go #2, задача G2-01)

- **Разделитель — точка с запятой**, не запятая. Загрузка:
  `COPY ... FROM ... WITH (FORMAT csv, DELIMITER ';', HEADER true)`.
- **Идентификаторы короткие**: `U_67`, `F_64255` — не `SYNTHETIC_U_000417`, как в примерах плана.
  Префикс `SYNTHETIC_` есть только в названиях колонок.
- **Булевы метки лежат как `0.0` / `1.0`** (float, не bool): все `CL_PRODUCT_*_MARK`,
  `FTS_FLAG`, `FACTORING_MARK`, `NEGATIVEMARK`. При загрузке приводим к boolean.
- **`FTS_COUNTRY_NAME` может содержать несколько стран через запятую**:
  `КИТАЙ, ТУРЦИЯ`, `ОАЭ, ИНДИЯ, КИТАЙ`. Матчинг по стране — разбором списка,
  а не сравнением строки целиком. Заполнено примерно у 8 400 компаний из 85 525.
- `AMOUNT_WORKERS_SPARK_GRADATION` и часть других полей бывают пустыми — это
  штатный случай (Ограничение 05 кейса про неполные данные).
- Единицы `REVENUE_COMPANY` в кейсе не указаны: встречаются значения вида `136493.0`,
  похоже на тысячи рублей. Уточнить у организаторов до того, как на выручке
  построится отсечение «крупный бизнес от 15 млрд».

## Что важно знать про PDF (Go #1, задача G1-13)

**Это сканы: текстового слоя в файлах нет вообще.** `pdftotext` возвращает ноль символов
по всем девяти. Поэтому чанки режутся по OCR:

```
pdftoppm -r 200 -png стр → tesseract -l rus+eng → текст страницы → чанки
```

Проверено на `alfa_policy_rate_11sep.pdf`: OCR даёт чистый русский текст без артефактов.
OCR бесплатный и офлайновый, токены моделей на это не тратятся. Разрешённая
мультимодальная модель (Qwen3-VL) остаётся в резерве для графиков и таблиц.
